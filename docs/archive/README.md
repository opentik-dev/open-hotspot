# Documentation archive

This directory contains historical evidence and release records retained for
auditability and rollback context. It is outside the active decision path.

Agents must use [`../source-of-truth.md`](../source-of-truth.md), the current
gate register, and the active operational ledger first. Archive contents must
not be treated as current candidate state, deployment instructions, or release
acceptance.

## Contents

- [`evidence/`](evidence/) — dated field observations and target checkpoints.
- [`operations/`](operations/) — the full append-only operational history.
- [`releases/`](releases/) — historical artifact and release checkpoints.
